# Pencilscript
This is my repo for my coding language PencilScript. The current version is Alpha 1.0, and Alpha 1.1 will come out very soon. In fact, Alpha 1.1 is in development **right now!** Pencilscript is meant to be a flexible, yet readable coding language. And we are not talking about Python's "readability", we mean you could read your code like a book!
