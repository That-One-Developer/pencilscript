About

Pencilscript is...

A coding language designed to be as english like as possible, while still being flexible and not restrictive.

Why?

When you have bugs, Pencilscript is easy to debug because you don't have to guess what your code does.

When?

Pencilscript works offline, so you don't need an internet connection

Where?

Anywhere! Quite literally, if you have a computer and pencilscript, it will work... as long as the computer is working.
